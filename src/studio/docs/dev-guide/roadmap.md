## 当前版本：最小闭环（感知 + 理解）

验证策略：先做高频路径（每天记想法、理想法），真实使用 1-2 周后按使用检验决定后续功能。

### 感知页（思维收集）

- [ ] 想法输入（零门槛，想到就记）
- [ ] 想法流时间线（原始想法：时间、来源、内容）
- [ ] 导入素材（quanttide journal 日志导入）

### 理解页（AI 加工 + 澄清）

- [ ] 清晰度判断（AI 判断清楚/不清楚，用户标记需澄清）
- [ ] 澄清对话（模糊想法多轮澄清）
- [ ] 加工结构化（AI 拆解 事实/感受/行动，用户确认/修改）
- [ ] 情境意识实例（加工完成即形成实例，界面呈现实例列表）

## 后续（延迟验证，暂不排期）

- 预测页（识别模式 / 推演走向）——等实例数据积累后验证
- 决策页（确立目标 / 记录决策）——同上
- 导航 4D 完整化（当前最小闭环先做感知/理解两环）

## 验证标准

- 真实使用：主动用 / 缺了难受 = 值得做
- 砍掉验证：砍掉不受影响 = 不值得做
- 数据驱动：按使用频率砍死功能、深化活功能

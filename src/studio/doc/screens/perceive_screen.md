# 感知页（perceive_screen）设计

> 4D 认知过程第一环：感知——思维收集，零门槛

## 定位

用户想到就记的地方。核心原则：**零门槛，不打断**——输入动作最短，不要求整理、不要求写清楚。

## 功能区

```
┌──────────────────────────────┐
│ 输入区（底部固定）              │
│  [输入想法…            ] [记]  │
├──────────────────────────────┤
│ 想法流（时间线，倒序）          │
│  · 08-22 09:41  手输          │
│    "产品云的地图列应该…"        │
│  · 08-22 09:12  手输          │
│    "验证比规划重要"             │
│  · 08-22 08:00  journal 导入   │
│    "（日志片段）"              │
└──────────────────────────────┘
```

## 交互行为

### 输入

- 底部输入框：Enter/点击"记"提交 → 生成 Thought(raw)，插入时间线顶部
- 提交后输入框清空，不跳转（连续记不打断）

### 想法流

- 倒序时间线：时间 + 来源标签（手输 / journal 导入）+ 内容
- 点击想法 → 跳转理解页（该想法进入加工）
- 来源标签：手输（默认）/ journal 导入（标识来源日志）

### 导入素材

- 入口：顶部/菜单"导入 journal"
- 选择 quanttide journal 日志 → 批量生成 Thought(raw)（来源=journal 导入）

## 数据

| 项 | 说明 |
|----|------|
| 输入 | Thought(content, source=手输, status=raw) |
| 时间线 | 全部 Thought 倒序（status=raw 优先完整显示） |
| 导入 | Thought 批量（source=journal 导入） |

## 验收

- 输入一个想法 → 立即出现在时间线顶部（不打断）
- journal 导入 → 批量想法生成
- 点击想法 → 跳转理解页

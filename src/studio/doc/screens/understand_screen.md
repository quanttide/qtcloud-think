# 理解页（understand_screen）设计

> 4D 认知过程第二环：理解——AI 加工、人类挑选

## 定位

把模糊想法加工成清晰结构的地方。核心分工：**AI 加工（判断/拆解）、人类挑选（确认/修改）**。加工完成即形成情境意识实例。

## 功能区

```
┌──────────────────────────────────────┐
│ 想法区（当前处理的想法）                  │
│  "产品云的地图列应该…"（来源：感知页）      │
├──────────────────────────────────────┤
│ 清晰度区                              │
│  AI 判断：🔴 不清楚 → [开始澄清]         │
│  （或 🟢 清楚 → [开始结构化]）           │
├──────────────────────────────────────┤
│ 澄清区（模糊想法多轮对话）                │
│  AI: 你说的"列应该…"具体指什么？         │
│  用户: …                              │
│  [输入回答…] [发送]                    │
├──────────────────────────────────────┤
│ 结构化区（AI 拆解 + 用户确认）           │
│  事实: …       [编辑]                  │
│  感受: …       [编辑]                  │
│  行动: …       [编辑]                  │
│  [确认加工]                            │
├──────────────────────────────────────┤
│ 实例区（情境意识实例列表）                │
│  · 08-22 已加工 "验证比规划重要…"        │
│  · 08-21 已加工 "…"                    │
└──────────────────────────────────────┘
```

## 交互行为

### 清晰度判断

- AI 对进入本页的想法判断 清楚/不清楚
- 清楚 → 直接显示"开始结构化"
- 不清楚 → 显示"开始澄清"

### 澄清对话

- 多轮：AI 追问 → 用户回答 → AI 再问/总结
- 澄清完成（AI 判断已清楚）→ 进入结构化

### 结构化加工

- AI 拆解 事实/感受/行动 三清单
- 用户可编辑每一项（AI 加工、人类挑选）
- 点击"确认加工" → Thought 状态=structured（**即情境意识实例**，无独立升级动作）

### 实例区

- 已加工想法列表（时间 + 内容摘要）
- 实例可再次点开查看/编辑

## 数据

| 项 | 说明 |
|----|------|
| 清晰度 | Thought.clarity（AI 判断，用户可标记） |
| 澄清 | 对话记录（多轮，存 Thought.clarifying 上下文） |
| 结构化 | Thought.facts/feelings/actions（用户确认后落库） |
| 实例 | Thought(status=structured) = 情境意识实例 |

## 测试（screens/understand_screen_test.dart）

- 清晰度分支（假 clarify：clear → "开始结构化"；unclear → "开始澄清"）
- 澄清对话（输入回答 → 发送 → 对话追加）
- 结构化确认（点"确认加工" → 仓储 update 为 structured → 出现在实例区）
- 失败提示（clarify 抛错 → 显示错误，想法保持 raw）

## 验收

- AI 判断清晰度 → 清楚/不清楚 分支正确
- 模糊想法多轮澄清后进入结构化
- 确认加工 → 想法出现在实例区（状态=structured）
- 实例可回看/编辑
